# 双语切轨帧复算例

样例 `sample_data/bilingual`：简中原轨与英语译轨各 5、4 条字幕，切版 A-01 保留源 [0,500) 锚到目标 0，A-02 移除 [500,700)，B-01 保留 [700,1200) 锚到目标 401。换算比 `1001/1250`。

## 请求落在原句中间

请求在目标帧 **350** 由简中切到英语。反查 A-01：源点 `= 350 × 1250/1001 ≈ 437.06`，落在原句 Z2（源 [400,600)，原行 3）中间。立即换轨会截断 Z2，因此顺延到 Z2 的交付末帧：A-01 内 `[321,401)` 与 B-01 锚点 401 首尾相接，实际切轨帧 **401**，规则 `SWITCH_DEFER_CUE_END`。

取舍（半开帧，以 401 为界）：

| 轨道 | 字幕 | 状态 | 切轨前帧 | 切轨后帧 | 依据 |
|---|---|---|---|---|---|
| 简中 | Z1/Z2 | 切前播完 | 120 / 80 | 0 | 原行 2、3 |
| 简中 | Z3/Z4 | 切后弃用 | 0 | 160 / 40 | 随切轨弃用 |
| 英语 | E1/E2 | 漏播 | 120 / 40 | 0 | 切轨前已开播 |
| 英语 | E3/E4/E5 | 切后播放 | 0 | 160 / 120 / 32 | — |

## 覆盖对账与重播

- 简中：KEEP 并集 400 帧 = 切前 200 + 切后 200，差额 0。
- 英语：KEEP 并集 432 帧 = 切前 160 + 切后 272，差额 0。
- 重播：E3 `[442,602)` 与 E4 `[562,682)` 在切轨后重叠 `[562,602)`，深度 2 的 40 帧只计一次（原行 8、9）。
- 汇总：漏播 160、弃用 200、重播 40，延迟原句 1 条。

## 待证区与重叠原句

- 请求帧落在 KEEP 段之间的目标待证区（如自定义切版中 `[81,500)`）时，顺延到下一 KEEP 锚帧 500，规则 `SWITCH_GAP_ADVANCE`，响应 `gap` 给出待证区间。
- 两条原轨字幕重叠时，顺延到第一条末帧后第二条仍跨过切点，定点循环继续后移，直到没有原句 `[start,end)` 包含切点，每条被延迟的原句都记入 `active_cues`。

## 幂等与签发

档号由 `venue-switch/1`、原件 SHA-256 与请求 SHA-256 共同寻址。同一请求重试（含 `/repeat`）命中硬链接复用，`reused=true` 且目录下仍只有一份 JSON。`/api/switch/runs/<id>/export` 签发前核验原件、请求、结果三份散列与覆盖勾稽，任一被改即返回 `INVALID_SWITCH_EVIDENCE`。
